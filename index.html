Este index.html é o código-fonte e só funciona com o servidor de desenvolvimento. Para usar o editor:

Opção 1 — sem instalar nada: abra o arquivo dist-single/index.html.

Abrir a versão portátil →

Opção 2 — instalar como aplicativo (recomendado): no terminal, dentro da pasta do projeto:

npm install
npm run app

e abra http://localhost:4173 no Chrome/Edge → Instalar. (Para desenvolver: npm run dev.)

Se abriu direto de dentro do .zip, extraia o zip inteiro para uma pasta antes — o botão acima precisa da pasta dist-single ao lado.
